# 贡献规范

## 内容规范

- 教程页必须包含四段：`目标`、`前置条件`、`步骤`、`预期结果与排错`。
- 命令必须可复制执行。
- 示例密钥必须使用占位符，不得提交真实凭据。
- 涉及能力状态（可用/未提供）时，必须先与最新代码行为核对。

## 资源规范

- 图片放在 `docs/.vuepress/public/images/...`
- 文件命名建议：`{page}-{step}-{yyyyMMdd}.{png|svg}`
- 每张图片下方补一句“你应该看到什么”。

## 提交流程

1. 本地运行 `pnpm docs:dev` 自查。
2. 执行 `pnpm docs:build` 确认无构建错误。
3. 提交前检查死链、术语统一和代码片段可读性。

## 导航同步检查（必须）

每次新增或删除中文页面后，必须同时检查这两处是否同步：

- 顶部导航：`docs/.vuepress/configs/navbar/zh.ts`
- 侧边栏导航：`docs/.vuepress/configs/sidebar/zh.ts`

尤其是二级菜单（下拉项）必须与对应分组页面保持一致，避免出现“有页面但菜单缺项”或“菜单有项但页面不存在”。
