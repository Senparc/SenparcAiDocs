# 快速上手

本章目标是帮助你在最短时间内跑通 `Senparc.AI.Samples.AgentKernelConsoles` 项目，此项目是 `Senparc.AI` 的示例项目，用于演示 `Senparc.AI` 的核心用法，也是你学习 `Senparc.AI` 的最佳实践的最佳路径。

## .NET 10 安装（简版）

如果你机器里还没有 `.NET 10`，可按下面任一方式安装：

1. Windows（winget）：

```bash
winget install Microsoft.DotNet.SDK.10
```

2. macOS（Homebrew）：

```bash
brew install dotnet@10
```

3. Linux（APT 示例）：

```bash
sudo apt-get update
sudo apt-get install -y dotnet-sdk-10.0
```

4. 安装后验证：

```bash
dotnet --version
```

预期输出为 `10.0.x`。
