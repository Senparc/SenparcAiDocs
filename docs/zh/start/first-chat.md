# 第一次 Chat 成功

## 目标

通过菜单 `[1] Chat` 完成一次多轮对话，确认 AgentSession 已生效。

## 前置条件

- 已完成 [获取代码并运行](/zh/start/clone-and-run.html)
- 至少一个 Chat 模型可用（例如 `gpt-4o`）

## 步骤

1. 启动 Sample 后输入 `1` 进入 Chat。
2. 按提示输入 System Message（留空可用默认值）。
3. 选择会话模式：
- `1` 共享 AgentSession（推荐）
- `2` 每轮新建 Session（用于对比）
4. 输入问题，例如：

```text
苏州特产有哪些？请说三个。
```

5. 再输入追问：

```text
南京的呢？
```

## 预期结果与排错

- 预期：模式 `1` 下，第二轮回答可保留上下文信息。
- 预期：输出中会看到 Token 统计（input/output/total）。
- 若没有上下文效果：确认你选择了模式 `1`。
- 若返回 401/403：检查密钥和 Endpoint。
- 若响应极慢：先切到轻量模型或关闭本地代理干扰。
