# Quick Start

This chapter helps you run `Senparc.AI.Samples.AgentKernelConsoles` in the shortest time. This sample is the best entry path to learn the core usage and practices of `Senparc.AI`.

## Install .NET 10 (Short Version)

If `.NET 10` is not installed on your machine, use one of the following methods:

1. Windows (winget):

```bash
winget install Microsoft.DotNet.SDK.10
```

2. macOS (Homebrew):

```bash
brew install dotnet@10
```

3. Linux (APT example):

```bash
sudo apt-get update
sudo apt-get install -y dotnet-sdk-10.0
```

4. Verify installation:

```bash
dotnet --version
```

Expected output: `10.0.x`.
