# Unsupported Capabilities (Current State)

In `Senparc.AI.Samples.AgentKernelConsoles`, the following menu items currently show "Not Provided":

- Planner task planning
- PluginFromObject / Function Calling

This is the known current state of the sample, not an environment issue on your side.

## Alternatives

- For currently stable AgentKernel capabilities, prioritize Chat/Completion/Embedding/RAG/Image/STT/TTS.
- `Senparc.AI.Kernel` has been discontinued and is not recommended as a new-route fallback.
